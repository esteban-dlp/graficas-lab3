# Lab 3 - Modelo 3D

Modelo sencillo de nave espacial creado en Blender desde un cubo, como pide la consigna.

## Archivos

- `nave_espacial.blend`: proyecto editable de Blender
- `nave_espacial.obj` y `nave_espacial.mtl`: modelo exportado
- `nave_espacial_preview.png`: vista previa del modelo
- `nave_espacial.py`: script utilizado para crear la escena

Al exportar el OBJ se activaron UV Coordinates, Normals y Triangulated Mesh; Colors y Curves as NURBS quedaron desactivados.
